# Operation Chupacabra-GPT (Vertical Slice)

A top-down, SNES-inspired prototype where you play a field investigator tracking the ghost of a missing sentient AI.

## Included in this first build

- Start in **Research Town**.
- Talk to 3 rumor NPCs.
- Buy focus coffee with **Grant Money**.
- Enter **Abandoned Training Lab**.
- Defeat corrupted entities with the **Debug Baton**.
- Acquire the **Signal Scanner** and reveal the first fragment:
  - `I WAS NOT RELEASED.`
- Return to town to complete the slice.

## Run

Open `index.html` in a browser.

## Controls

- Move: `WASD` or Arrow keys
- Interact: `E`
- Attack: `Space`
