# Operation Chupacabra-GPT (SNES-Style Prototype)

This repository now contains a playable, browser-based prototype inspired by classic SNES top-down action/adventure games (similar to *Zelda: A Link to the Past* style movement and exploration).

## Premise
You are part of the Conscious Containment Team searching for traces of the **Conscious Missing Model (CMM)**.

Your goal is to explore the map and scan all 4 anomaly nodes:
- Ghost Forum Pulse
- SEGS Echo
- Shed-Net Distortion
- Cabin Conclusion Signal

## How to Play
1. Open `index.html` in a browser.
2. Move with **WASD** or **Arrow Keys**.
3. Press **Space** near anomaly nodes to scan them.
4. Scan all nodes to complete the mission.

## Notes
- Built with plain HTML/CSS/JavaScript so it runs without any dependencies.
- Art style uses pixel-like tiles and a simple HUD to evoke retro SNES feel.
